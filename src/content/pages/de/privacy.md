Dies ist ein privater, nicht kommerzieller Blog. Ich bearbeite so wenige Daten wie möglich. Diese Erklärung richtet sich nach dem Schweizer Datenschutzgesetz (DSG) und, soweit anwendbar, nach der EU-DSGVO.

## Verantwortliche Person

Markus Tobler, Schweiz. Kontakt über ein Issue auf [GitHub](https://github.com/markus-tobler/ai-tech-blog/issues).

## Hosting

Die Website wird auf GitHub Pages von GitHub, Inc. (USA) betrieben. Bei Ihrem Besuch bearbeitet GitHub technische Daten wie Ihre IP-Adresse, um die Seiten auszuliefern und den Dienst zu schützen. Siehe die [Datenschutzerklärung von GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Schriften

Alle Schriften werden von dieser Website ausgeliefert. Ihr Browser stellt keine Anfragen an Schriftanbieter.

## Besucherstatistik

Ich zähle Seitenaufrufe mit [GoatCounter](https://www.goatcounter.com/). GoatCounter setzt keine Cookies und speichert weder IP-Adressen noch persönliche Kennungen. Erfasst werden Seite, Herkunftsseite, Browser, Bildschirmgrösse und das ungefähre Land. Mehr dazu in der [Datenschutzerklärung von GoatCounter](https://www.goatcounter.com/help/privacy).

## Kommentare

Kommentare laufen über [giscus](https://giscus.app/) und werden als GitHub Discussions im Repository dieses Blogs gespeichert. Der Kommentarbereich lädt erst, wenn Sie dorthin scrollen. Zum Kommentieren melden Sie sich bei GitHub an, es gelten die Datenschutzbestimmungen von GitHub. Ihre Kommentare sind öffentlich.

## Ihre Rechte

Sie können Auskunft über die zu Ihnen bearbeiteten Daten verlangen und deren Berichtigung oder Löschung beantragen. Kontaktieren Sie mich wie oben beschrieben. Eigene Kommentare können Sie direkt auf GitHub bearbeiten oder löschen.
