# Language guidelines

## English (en-GB), primary language

- British spelling: organisation, optimise, colour, behaviour, centre, licence (noun), programme (non-software), modelling, labelled. Vale enforces the common cases.
- Dates: 2 November 2026. Numbers: 1,000.5. Currency: CHF 1,200 or EUR 500.
- Single quotation marks for quotes, double for quotes within quotes: 'He said "no".'
- No Oxford comma unless it avoids ambiguity.
- Sentence case for titles and headings.
- Contractions are fine (it's, don't). Avoid jargon a leader would not use; explain acronyms on first use.

## Swiss Standard German (de-CH), optional translation

- Swiss spelling: always `ss`, never `ß` (gross, Strasse, gemäss, äussern).
- Quotation marks: «…» and ‹…› for inner quotes.
- Address readers with «Sie». Neutral constructions are fine.
- Dates: 2. November 2026. Numbers: 1'000.50 (apostrophe as thousands separator). Currency: CHF 1'200.–
- Prefer Swiss terms where they differ: parkieren, Velo, Traktandum, allenfalls, Offerte.
- Gender-inclusive language, preferably neutral (Mitarbeitende, Fachleute) or paired forms (Architektinnen und Architekten). No gender star.
- Established English product and role terms stay English: Citizen Developer, Copilot Studio, Power Platform, Prompt, Agent where common. Explain on first use if needed.

## Translating EN to DE

- Translate meaning, not words. Rebuild sentences so they read as written in German.
- Keep structure, headings, links and code identical; translate code comments only if helpful.
- Keep `translationKey`, `topic`, `tags`, `audience` and `pubDate`; set `lang: de` and `aiAssistance: translation` (or as appropriate).
- Link to German versions of sources where they exist.
- Titles may differ to sound natural, but promise the same content.
